# 表达偏好校准与段落优化实施计划

状态：执行中。范围为全局指令中的表达段落；本计划不授权安装技能或改动运行中的指令。

## 目标与依据

依据用户 D01–D12 的人工反馈、随后对预防性自我辩护的确认，以及
[Humanist 质量评测](https://github.com/itsryanlenk/humanist/blob/main/docs/evals/quality-benchmark.md)
的方法调研，改进测量后再比较段落。采用五项检查：回应问题、判断有据、推进理解、
自然易读、预防性自我辩护。内容准确性、必要条件、深度和查阅结构单独检查。

预防性自我辩护包括：引入与当前问题无关的异议，通过否定它保护回答者的立场或形象；
也包括没有否定词的立场补充。逐句检查澄清对象、信息增量和删除后果。
具体误解、真实风险和影响决策的限制应保留。评价文本作用，不推断模型内在动机。

## 范围与文件职责

- `evaluations/communication-style/preference-calibration/`：原始标签、题目、准入分类、
  五项裁判、执行记录、分歧分析及后续冻结的保留组。
- 本计划：阶段依赖、开始条件、验证和未完成事项。
- `docs/sources.md`：Humanizer/Humanist 的来源、版本与证据限制。
- `tests/test_preference_judge.py`：准入、输出校验、顺序归一、缺失/失败记录及只读汇总。
- 原题包、旧评分标准、既有研究记录保持可复现；使用新文件版本，不改历史标签。

不进行整套技能清理，不计算固定句级贡献比例，不新增私有对话读取，不改安装状态、
全局模板或发布标签。不以缩短文字、去除否定句、裁判高分作为单独采用依据。

## A. 题目准入与五项裁判

前置：已有人工反馈。为全部 24 题记录作者准入判断与理由，类别为表达比较、混合差异、
独立正确性控制。分类无偏好答案，不发送给裁判。D09 不参与表达评分；D01/D08 不补标签；
D03 保留 B 选择并标注混合因素。对保留题仅做准入检查，不收集或使用其人类偏好。

实现带版本的独立裁判协议：偏好、双方问题、共有问题、各自优点、内容损失、预防性
自我辩护专项判断。证据用段落 ID，程序提取原文；优点和问题可为空，不强迫凑数。
自辩判断须解释澄清对象、信息增量和删除后果。输入仅含语境和候选，排除来源、作者
probe、准入类别和人工标签。相同文本控制允许平局，人工未知不变成平局。

验证：定向 pytest、Ruff、格式、Pyright、Markdown/链接与三个 Git diff 面检查。
准入覆盖所有题；事实相反题不能进入表达一致率；交换后选择回到原答案身份；
非法或跨答案证据、未知字段、缺失输出均须显式失败。测试通过后冻结源文件摘要并提交。

## B. 校准组执行与分歧审核

依赖 A。首批仅对 11 个非正确性控制题做两种顺序，加一个相同文本控制的两种顺序，
最多 24 次调用；一次尝试，不自动重试，不补齐失败。使用已有隔离 Pi 调用入口，
`openai/gpt-6-sol`、high、并发 3、超时 300 秒。保留可见答案、配置、使用量、错误；
不记录隐藏推理。先前调用存在时拒绝覆盖，不根据分数挑选尝试。

原始选择一致率按题报告，顺序冲突单列；混合题与无标签题仅做分开诊断。报告各来源组
计数，不将换序或同源变体计为独立样本，不凭作者分类计算缺陷检出率。
审核全部可见输出，特别检查双方共有缺陷、失败版本优点、自辩的澄清对象与实际作用。
校准分歧不能靠加入题号答案消除。若有系统性遗漏，记录并修订下一版；不启动保留组。

验收：生成可离线复现的计数和独立作者审核，解释与人工反馈的具体一致和分歧。
这一步不要求凑满一致率，也不宣称裁判已得到独立验证。

## C. 冻结与保留组

依赖 B 的审核决策。固定裁判文本、模型、输出结构、交换规则、统计口径和失败规则，
明确最终选择的版本后，再生成合格保留题的简短标注包并请用户标注。
不得用校准标签推导保留标签。原有保留题仅在本轮校准中留出，作者已见过材料，
不声称是完全未见的新基准。若保留反馈用于调参，降为开发材料并补充新来源组。

验收：报告胜负标签一致/不一致、未知与无效覆盖、换序冲突和实际分歧。
人工阅读时间优先投入裁判分歧及误伤正常表达，不以模型间一致替代用户偏好。

## D. 首次生成段落对照

依赖 C 对裁判适用范围的确认。另行冻结当前段落与一个候选段落、8–12 个独立对话场景。
覆盖四类领域、短答和连贯长答，以及应当保留的纠错、限定、例子和列表。提供足够上下文，
避免题面直接要求不要自辩。第一批每场景每版本一次；增加场景或重复须由观察到的问题决定。

候选不包含 Humanizer 的标点禁令、词汇黑名单和自动补事实。先生成后匿名换序判断，
报告偏好、共有问题、具体损失、目标问题变化和来源组计数。针对规则作用不清之处，
可另做原稿/普通润色/规则润色的同源比较，控制模型与编辑轮数；改写不是必经阶段。

验收：用户抽查胜出、退步及分歧样本；内容、推理和查阅结构没有被精简损坏。
结果混合则保留当前段落。运行时采用仍需用户确认，首次生成与完整指令栈效果分别报告。

## 风险、回退与验证边界

- 小样本、同家族裁判、作者编写对照会限制泛化；不报告虚假的精确权重。
- 相同文本强选、缺失标签补齐、重复调用当独立样本会制造结果；实现中明确拒绝或分开统计。
- 结构校验不能证明语义判断正确，模型批评不能直接充当人工缺陷标签。
- 新版文件可停用；保留全部旧材料与失败记录即可回退。没有运行中配置需要恢复。
- 本轮先以评估脚本和相关测试为最小检查面；共享入口若改变，扩大到其相关测试。
  最终交付说明定向检查、全仓检查是否执行、未完成的人类标注和外推边界。
