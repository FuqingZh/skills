# 两组回答比较

每题选更愿意收到的回答：A、B、相当或拿不准。
两份都不好也可以直接指出。愿意的话，说说具体哪句话好或不好。

## P01

**问题**：我每天晚上都想着只刷十分钟短视频，结果常常拖到半夜。为什么这么容易停不下来？

### A

短视频不断给出下一条内容，继续看几乎不用做决定，停下来反而需要主动结束。于是，“再看一条”很容易接成许多条，睡觉的时间就被推后了。个人选择当然也有作用。

### B

## P02

**问题**：为什么盖上盖子通常能让热水凉得慢一些？我知道蒸发会带走热量，但没想明白盖子怎样影响蒸发。

### A

盖子让水面附近的水汽不容易被空气带走。水汽在杯内积聚后，回到液面的水分子增多，净蒸发的速度就会降低。蒸发带走的热量减少，水通常就凉得慢一些。

### B

盖子让水面附近的水汽不容易被空气带走。蒸发带走的热量减少，水通常就凉得慢一些。
