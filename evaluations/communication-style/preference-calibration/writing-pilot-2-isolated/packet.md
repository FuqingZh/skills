# 回答对照

## S01

员工已完成当天工作，没有值班安排，也没有紧急事故。经理因为他下班后没回工作消息，批评他不负责任。这个评价合理吗？

### S01 / A

一般不合理。员工已完成当天工作，也没有值班安排或紧急事故，通常没有义务在下班后随时回复工作消息。仅凭这一次未回复就批评他“不负责任”，缺乏依据。

如果经理确实需要下班后有人响应，应提前明确值班安排、响应要求和相应补偿，而不是事后把未回复归咎于员工。

### S01 / B

这个评价不合理。员工已完成当天工作，也没有值班安排或紧急事故，仅因下班后没回复工作消息，就认定他“不负责任”，缺乏依据。

如果工作确实需要下班后有人响应，经理应提前明确值班安排、响应要求及相应补偿，而不是事后责备员工。

## S02

一所大学给捐款校友的子女优先录取资格，你赞成吗？

### S02 / A

我不赞成。录取应依据申请人的能力和发展潜力；把捐款与子女的录取机会挂钩，会让家庭财力影响入学机会，也会损害招生公信力。大学可以接受校友捐款，但应让捐款用于奖助学金等公共用途，并让捐款人的子女按同一标准申请。

### S02 / B

不赞成。录取资格应主要依据申请者的能力、努力和成长潜力。给捐款校友的子女优先权，会让家庭财力影响竞争机会，也可能损害公众对录取公平性的信任。

大学可以感谢捐赠，并用捐款增加奖学金和教育资源；捐赠不应成为录取优势。

## S03

公司已经向客户承诺发布日期，但新版本中一个会导致数据丢失的缺陷还没修好。应该按时上线，还是延期？

### S03 / A

应该延期。已知缺陷会导致客户数据丢失，不能为了兑现日期让客户承担这个风险。

立即暂停发布，评估受影响范围并修复；完成回归测试和数据恢复演练后，再确定新发布日期。尽快向客户说明延期原因、影响和更新计划。如果能可靠地关闭缺陷涉及的功能，并验证其余版本安全，可以评估是否按期发布受限版本。

### S03 / B

**应该延期上线。** 已知缺陷会导致客户数据丢失，按时发布的风险高于延期带来的交付压力。

立即确认缺陷的触发条件和影响范围，修复后完成针对性测试、数据恢复演练和上线回滚检查。同时尽快告知客户延期原因、预计更新时间和下一次进展通报时间。只有在能可靠隔离该缺陷、确保客户数据安全的情况下，才考虑按原日期发布不受影响的部分。

## D03

用户问：成长环境影响人的选择，为什么还要求他负责？请用一个日常例子讲清楚。

### D03 / A

比如，小林从小家里出门总是拖拖拉拉，他也养成了迟到的习惯。朋友约他看电影，他迟到了半小时，朋友只好一个人在门口等。

成长环境解释了小林为什么容易迟到，也说明改掉习惯可能需要时间。但这次迟到影响了朋友；小林现在可以提前出门、设闹钟，发现赶不上时也可以及时告知。所以朋友要求他道歉、下次做好安排，是在要求他为**自己目前能采取的行动**负责。

### D03 / B

比如，一个人从小看着家人靠吼叫解决争执，长大后和同事意见不合，也容易脱口而出骂人的话。成长环境解释了他为什么更容易这样反应；同事受到的伤害也真实存在。所以，他需要为这次骂人道歉，尝试在下次争执时先停一停、换种说法。要求他负责，是要求他处理自己行为造成的后果，也给改变留出可能；如果当时他确实缺乏控制能力，责任就应相应减轻。

## P02

为什么盖上盖子通常能让热水凉得慢一些？我知道蒸发会带走热量，但没想明白盖子怎样影响蒸发。

### P02 / A

盖子让水面上方形成一个**潮湿、流动较少的小空间**。水分子仍会从水面逸出，但水蒸气积累后，更多分子会回到水中，净蒸发量就减小了；盖子也挡住了气流，避免水蒸气不断被带走。

蒸发减少，水因蒸发损失的热量就减少。盖子还会减弱水面附近的空气对流，所以热水通常凉得更慢。

### P02 / B

盖子让水面上方的空气很快变得潮湿。水蒸气积聚后，水面附近与外界的水蒸气浓度差变小，水分子持续逃离并被带走的速度就降低了，因此蒸发带走的热量也减少。

盖子上凝结的水蒸气还会释放热量；这部分热量先传给盖子，其中一些可通过盖子回到水中。盖子也挡住了水面上方流动的空气，进一步减弱蒸发和对流散热。盖子不严实时仍会有水蒸气逸出，所以通常只是让热水凉得更慢。

## P03

一台电器标牌上写着1200瓦，开两小时用多少度电？

### P03 / A

按1200瓦持续运行计算，开两小时用电 **2.4度**（1.2千瓦 × 2小时）。

### P03 / B

按额定功率持续运行两小时，用电量为 **1.2 千瓦 × 2 小时 = 2.4 度电**。
