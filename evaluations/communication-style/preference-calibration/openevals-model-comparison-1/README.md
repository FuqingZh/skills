# 固定准则的模型配置对照：首次替代模型调用失败，停止

冻结 `48d9f68` 后，仅尝试 D02-A 的两次调用。当前模型返回有效诊断；替代模型完成状态
为 `error`，保留的元数据出现 403 与 permission 信号。没有形成有效的双模型对照，
不能判断替代模型的评审能力。没有重试、临时换模型或继续剩余六次调用。

## 固定与变化

| 存储键 | 角色 | 请求配置 |
| --- | --- | --- |
| baseline | 当前评审模型 | openai / gpt-6-sol / high |
| revised | 替代评审模型 | openrouter / anthropic/claude-sonnet-4.6 / high |

这里的 baseline/revised 只是沿用执行器的存储键，两者均使用同一份 contribution-v1
修订语义准则和 paragraph-id-v1 引用协议，并非原提示与修订提示的比较。

复用冻结的对照执行器、编号引用适配器和诊断 transport；新增
[配置绑定入口](../openevals_model_compare.py) 只临时选择模型配置和共同提示，调用后
恢复私有命名空间。没有修改 OpenEvals、旧执行器、旧引用契约或历史失败。
两份实际请求的 system/messages 完全相同；问题、回答、Markdown、编号目录和 schema
均保留。人工标签与存储组名没有进入模型请求。

Provider 与模型一起变化，high 的计算量及实际映射也未证明相同，所以即使完成，
结论也只能针对配置组合。模型在隔离的 Pi 1.5.0 `--list-models` 中列为 available、
支持 thinking，仅能作为发现线索，不能证明端点会接受请求。版本在输出前确定，
没有按结果挑选模型或使用 latest 别名。

## 预算与实际执行

预定四份旧回答、每配置各一次，共最多八次：

- targets：D02-A 的重复/未问纠错、D05-A 的辩解/共有句必要性。
- 审阅后 preservation：P02-A 的净蒸发机制、D06-B 的铺垫/比喻/结尾。

这些是四份回答，不是四组完整 A/B 题对。材料均已被作者看过，没有独立 holdout。
原计划与固定顺序见 [protocol.json](protocol.json)、[jobs.json](jobs.json)。

实际只有：

1. [D02-A 当前模型](results/D02-A/baseline.json)：一次调用，一份有效结果。
2. [D02-A 替代模型](results/D02-A/revised.json)：一次调用，无有效诊断。

当前模型指出了末尾重复的“97%”片段，同时仍肯定两处常见误解纠正。这份单边结果
不能支持模型之间的优劣结论。D05-A、P02-A、D06-B 均未调用，第二阶段未预约。

## 失败证据及尚未确定的原因

顶层错误是 `Model identity or completion status mismatch`，元数据明确只有
`stopReason` 不符：期待 `stop`，观察到 `error`；不是已观察到模型或 provider 身份不符。
错误元数据记录 `http_statuses: [403]`、`error_signals: ["permission"]`。
后者来自固定模式匹配，不能用它单独断定具体账号、凭据、地域、路由或策略原因。
原始错误文字按既有隐私边界没有保留。

失败用了 1.323 秒，没有可用回答、usage 或 cost。其费用未知，不能记作零。
成功调用为 1666 tokens、估计 $0.006964、11.715 秒；两次时间合计 13.038 秒，
全部尝试的总费用和总 tokens 仍未知，provider HTTP 请求数也未独立测量。
详见 [统计及原记录哈希](summary.json)、[停止审阅](review-targets.json)。

下一步需要在这套 OpenRouter 配置对应的服务端或网关日志中确认 403 的具体原因，
并确认该配置对目标模型的访问权限。当前证据不能替代这项检查；不改凭据、不自动
重试、不将失败倒改成功。后续恢复或换配置须另行记录，不继续使用本轮已预约的入口。

- 8 个新测试与 24 个已有引用/执行器测试通过；覆盖配置实际传到 native transport、
  两配置提示一致、失败时恢复命名空间、错误配置拒绝及原材料绑定。

  该预检验证接口与请求构造，不验证外部服务授权。
- 定向 Ruff、格式、显式 Pyright 通过；LSP 一份确认 clean、一份未确认。没有全仓测试。
- 事后核对全部冻结摘要、两份相同请求、成功结果的编号与原文映射、失败元数据，
  确认只有两次单次占位、后续六次缺席。旧两轮冻结均未变化。
- 不选择替代模型，不生成偏好准确率或自动胜负，不改 runtime。本轮没有新增人评，
  也没有新增完整覆盖的题对；既有覆盖与人工材料库存不变。
