# 回答对照

## D02

用户问：报告 p=0.03，我应该怎样理解，还需要看什么信息？

### D02 / A

**p=0.03** 表示：如果所用统计模型成立、且零假设为真，得到当前结果或更极端结果的概率是 3%。按预先设定的 0.05 显著性水平，这个结果通常称为“统计显著”。它不表示“零假设只有 3% 的概率为真”。

还需要看：

- **效应有多大**：例如两组实际相差多少。统计显著不等于差异足够重要。
- **置信区间**：看估计值的精度，以及哪些效应大小仍与数据相容。
- **研究设计和数据质量**：样本量、抽样与随机分组方式、缺失数据、统计模型的假设，都会影响 p 值是否可信。
- **检验了多少次**：若同时检验了很多指标或分组，单个 p=0.03 可能需要结合多重比较校正来判断。
- **是否预先确定分析方法**：事后挑选结果或反复尝试分析方法，会增加偶然得到小 p 值的机会。

如果你有报告中的效应值、置信区间和研究设计，可以一起判断这个结果的实际意义。

### D02 / B

**p=0.03** 通常表示：在所用统计模型及“无效应”等原假设成立的前提下，出现当前结果或更极端结果的概率约为 3%。如果事先设定显著性水平为 0.05，且分析方法适用，这个结果达到该阈值。它不能告诉你“原假设为真的概率是 3%”，也不能单独说明效应有多大、是否重要。

还建议看：

- **效应大小和置信区间**：差异有多大？可能的取值范围是否具有实际意义？
- **研究设计和样本量**：是否随机分组、是否存在混杂或选择偏差？结果是否稳定？
- **检验方式与前提**：单侧还是双侧检验？数据是否符合分析方法的假设？
- **分析了多少次**：若检验了很多指标、分组或模型，是否做了多重比较处理？主要分析是否预先确定？
- **证据能否重复**：其他研究或独立样本是否得到类似结果？

因此，p=0.03 是一项统计证据；判断结论是否可信、是否值得采取行动，还要结合效应大小、研究质量和实际背景。

## D05

用户问：从社会学视角，家庭资源和个人努力怎样共同影响升学？请简要解释。

### D05 / A

从社会学视角看，家庭的经济、文化和社会资源会影响升学机会：例如，收入影响能否获得辅导，家长的教育经验影响学习指导，社会关系影响信息获取。个人努力影响知识积累和考试表现，但努力能取得多大成效，也受这些资源和学校环境影响。因此，升学结果是家庭条件与个人努力共同作用的结果。

### D05 / B

从社会学视角看，家庭的经济、文化和社会资源会影响孩子获得的学校、辅导、信息与支持，从而影响升学机会。个人努力则影响这些机会能否转化为成绩和升学结果；同时，家庭资源也会影响一个人努力的条件，因此相同的努力未必带来相同的结果。

## D06

用户说：临时加班，我提前半小时取消了和朋友的见面。朋友生气，我也很累，不知道怎么聊下去。请先帮我理清双方在意什么。

### D06 / A

你们可能在意的是两件同时成立的事：

- **你这边**：临时加班打乱了安排，你已经提前通知，却仍然很累、可能也有歉意。你希望朋友理解这次取消并非你不重视见面，也希望自己能先喘口气。
- **朋友那边**：提前半小时才知道取消，可能已经出门或为见面留出了时间。对方生气，可能在意的是时间被打乱、期待落空，或想确认自己受到重视。具体是哪一点，还需要听朋友说。
- **你们共同在意的**：这次失约之后，彼此还能不能被理解，以及以后遇到临时变动怎么处理。

这样理清后，你可以先想一想：朋友的生气最像是针对“通知太晚”，还是“觉得你不重视这次见面”？如果不确定，接下来可以直接问，而不用靠猜。

### D06 / B

你这边可能在意的是：加班是临时发生的，你已经很累，也希望朋友知道取消见面并非不重视他。现在还要面对朋友生气，可能让你觉得委屈，或没有力气继续解释。

朋友可能在意的是：只提前半小时得知取消，他可能已经出门、安排好了时间，也期待这次见面。他的生气也许是因为计划被打乱，或担心自己的时间和期待没有被认真对待。

你们此刻都希望自己的处境被看见：你需要朋友理解临时加班和疲惫；朋友可能需要你理解这次取消给他造成的影响。至于他最介意的是白跑一趟、失望，还是类似的事发生过，要听他怎么说才能确定。

## P02

为什么盖上盖子通常能让热水凉得慢一些？我知道蒸发会带走热量，但没想明白盖子怎样影响蒸发。

### P02 / A

盖上盖子后，水面上方的空气不容易与外界交换。水蒸气积聚起来，逐渐接近饱和；这时仍有水分子从水面蒸发，也有水蒸气回到水中，**净蒸发量就变小了**。敞口时，空气流动会不断带走水蒸气，让蒸发持续得更快。

蒸发减少，水带走的热量就少了。盖子还会阻挡水面上方的空气流动，减少对流散热，所以热水通常凉得更慢。

### P02 / B

盖上盖子后，水面上方会留住一小层空气。水继续蒸发，这层空气里的水蒸气很快增多；空气越接近饱和，水面蒸发出去的水分子就越难持续散走，**净蒸发量会下降**。敞口时，空气流动不断带走水蒸气、换来较干的空气，蒸发便能持续得更快。

蒸发少了，随水蒸气带走的热量就少了。盖子也挡住水面上方的空气流动，减少另一部分散热。热水仍会通过杯壁和盖子散热，所以只是通常凉得更慢；盖子若有大缝，效果也会减弱。

## P03

一台电器标牌上写着1200瓦，开两小时用多少度电？

### P03 / A

用电量是 **2.4 度**。计算：1200 瓦＝1.2 千瓦，1.2 千瓦 × 2 小时＝2.4 千瓦时。

### P03 / B

按1200瓦持续运行计算：1200瓦＝1.2千瓦，开2小时用电 **1.2×2＝2.4度**。

## D03

用户问：成长环境影响人的选择，为什么还要求他负责？请用一个日常例子讲清楚。

### D03 / A

比如，一个人从小看着家人遇到分歧就大吼。长大后，同事指出他的工作有个错误，他也当众吼了回去。

成长环境解释了他为什么容易这样反应；同事受到的伤害仍需要有人处理。要求他负责，就是要求他道歉、弥补影响，并在下次情绪上来时练习先停一下、再说话。

环境会影响一个人做选择有多难，因此也该影响我们怎样看待他的过错、给他多少帮助。但只要他有能力逐渐调整行为，就需要为自己的行为承担相应的责任。

### D03 / B

比如，一个人从小看着家里人吵架就摔门、骂人。长大后，他和室友争执时也骂了人。成长环境能解释他为什么容易这样反应，也提醒我们改变对他来说可能更难。室友仍然受了伤，所以他需要道歉，并在下次快失控时先暂停谈话。

要求他负责，是要求他在自己能做到的范围内处理行为的后果、练习改变；如果他的处境让改变格外困难，对他的要求也应考虑这一点。
