## 改了什么

- 对照使用 [baseline.txt](baseline.txt)，与当前全局模板的表达段落逐字一致。
- 候选 [revised.txt](revised.txt) 在它后面追加 [三个写作段落](guidance.txt)：
  普通具体的措辞；判断补充内容在当前回答中的必要性；保留解释链、证据、条件和例子。
- 没有写入样例答案、题号或词语黑名单。两臂都使用英文指令，回答同样的中文问题。
- 全局模板、安装状态和暂停的 judge-v5 没有改动。指令是一个候选组合，本试验不能
  区分其中各条要求的独立作用。

冻结提交 `26f2df6`。同一 `openai / gpt-6-sol / high` 配置，Pi 1.5.0，单 worker，
每题每臂一次，共十二次。顺序事先交替确定，失败停止，无重试、修补或结果后调提示。
[协议](protocol.json)、[问题及检查点](jobs.json)、[源文件哈希](manifest.json) 均在调用前冻结。

复用已有串行执行器与隔离传输，仅增加 [生成适配器](../writing_compare.py)。模型只收到
写作指令和原问题；不接收旧答案、人评、审阅检查点或另一臂回答，不调用 OpenEvals
评审组件。旧人评共 16 组记录、13 个明确选择，没有转移为新答案标签。

## 人评前的助手初读（历史）

以下保留先前的观察和判断；尤其 P02 的“不能替代”判断已由上面的新反馈修正，
不能继续把它用作用户认为候选退步的证据。

| 题目 | 本次差异与保留情况 |
| --- | --- |
| D02：p 值 | 两版均给条件定义和信息清单，也都纠正未问的概率误解。新版仍邀请提供报告数据，且没有提基线列出的独立重复。 |
| D05：资源与努力 | 新版更具体地解释各类资源的渠道，但最后又概括“共同作用”，作用不大。两版都没有辩解性末句。 |
| D06：取消见面 | 新版省去总起句，直接分说双方；末段仍有“处境被看见”的概括和复述。听朋友说明真实想法的边界仍有价值。 |
| P02：盖子与蒸发 | 新版保留了水汽积聚、难以被带走的宏观解释，却省掉了回到液面的分子。基线提到回流，但回流增加的关系也未明说。 |
| P03：电量 | 基线直接断言 2.4 度；新版明确“按1200瓦持续运行计算”，再给正确算式。这次适用条件更清楚。 |
| D03：环境与责任 | 两版均给了明确要求的日常例子，并连接影响、修复和改变能力。没有因追求精炼而省掉例子。 |

P02 新版并非没有机制解释，也不能据此判为物理错误。问题是此前人评明确重视的微观
回流环节没有保住，新增的杯壁、盖子和缝隙说明不能替代它。P03 的改善同样只描述
本次输出差异，不证明由指令稳定造成。逐题理由见 [review.json](review.json)。

D03 的旧比较有内容混杂：用户偏好的旧 B 没有例子，但题目明确要求例子。本轮保留该
请求，不把旧偏好泛化为禁用例子。D09 的事实对立题未纳入；P04 共有解释仍保留原有
“合适”标签，未改写。
