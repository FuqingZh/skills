# Research Working Material

Use when asked to retain research notes, explanation comparisons, or source
indexes across sessions. Follow the repository's research-record location or
the user's specified destination; otherwise use `.dissect/notes/`.

Keep observations, source references, competing explanations, uncertainties,
and next checks with the research task that owns them. Formal reports remain
in the project's maintained documentation or the user's requested output
location, regardless of which skill drafted them.

Reference available source material at its original location. Retain extra
evidence only when needed and not reconstructable from existing sources. Follow
the repository's evidence location; otherwise use `.dissect/evidence/`, excluded
from Git unless repository policy explicitly permits a narrow evidence file.
Follow repository policy for committing notes; absent a policy, keep them local
pending publication review. Hidden directories do not provide privacy or
publication rights; apply appropriate access controls to sensitive material.

Create only the files and directories needed for the requested persistence.
Preserve existing records, including `.traces/` material, without bulk migration.
Do not duplicate evidence when another skill later uses it; cite its owner.
