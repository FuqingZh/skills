# Decision Record

Record settled, high-impact choices whose rationale matters and cannot be
readily recovered from current code or architecture documents.

Use the [ADR](https://adr.github.io/) model;
[MADR templates](https://adr.github.io/adr-templates/) are optional format
references. Follow the repository's record format when defined.

- Follow the repository's decision-record location. If none is defined, use
  `docs/decisions/`.
- Record the decision date and status.
- Explain the context that made the decision necessary.
- Compare the viable alternatives that materially affected the choice.
- State the chosen decision and its consequences, including follow-up
  obligations.
- Record conditions that would justify reopening it.
