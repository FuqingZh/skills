# How-To Guide

Help a reader with the stated prerequisites perform and verify one concrete
task.

Use the [Diataxis how-to guidance](https://diataxis.fr/how-to-guides/) to keep
the guide focused on successful task completion.

- Follow the repository's how-to location. If none is defined, use
  `docs/guides/`.
- State the goal, scope, prerequisites, applicable versions, and assumptions.
- Give ordered, actionable steps with commands or exact interface labels
  where ambiguity would cause failure.
- Show the expected result and how to distinguish success from partial
  completion or failure.
- Link architecture, compatibility, or runbook documents when the task crosses
  those boundaries.
- State recovery or escalation guidance when a partial result can leave the
  system in a confusing or unsafe state.
