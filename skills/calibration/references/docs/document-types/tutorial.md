# Tutorial

Guide a reader from stated prerequisites to a demonstrable new capability.
Include enough context to complete the learning path without reconstructing
the conversation that produced it.

Use the [Diataxis tutorial guidance](https://diataxis.fr/tutorials/) to build a
coherent learning experience.

- Follow the repository's tutorial location. If none is defined, use
  `docs/tutorials/`.
- State the audience, prerequisites, and one tangible learning outcome.
- Sequence small steps that build toward the outcome.
- Use project commands, examples, and terminology from current authoritative
  sources.
- Include a verification or exercise that demonstrates the reader reached
  the outcome.
- Link external sources for claims that are not project-owned facts.
- Keep personal learner records and teaching-session notes outside team
  documentation.
